Azure SDK Blog, 2026-04-23 20:56 UTC

Azure MCP Server now available as an MCP Bundle (.mcpb)

Microsoft packaged the Azure MCP Server as a self-contained MCP bundle so it can be installed into Claude Desktop and other MCP clients without separately managing Node, Python, .NET, or Docker. That lowers setup friction for Azure-connected agent tooling and should widen adoption beyond developers who are comfortable with local runtime plumbing.
